Active Response

Active Response (often referred to as Automated Incident Response or Active Defense) is an automated security mechanism where a system directly intervenes to block, contain, or neutralize a detected threat in real time without waiting for human approval.

While passive defense only detects and logs an alert for an analyst to review, an active response system immediately executes a countermeasure to stop an attack mid-execution.

Common Active Response Actions

  • Network (Firewall / IPS)
  • Endpoint
  • Identity(IAM / IdP)
  • Email Gateway

Architectural Implementation: SOAR

  1. Detection
  2. Enrichment
  3. Decision Logic
  4. Execution

Riskd and Trade-Offs

  • Denial of Service via False Positives
  • Adversary Manipulation
  • Loss of Volatile Evidence
