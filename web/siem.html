Security Information and Event Management(SIEM)

SIEM (pronounced "seem") stands for Security Information and Event Management.

It is a centralized security software solution that collects, analyzes, and correlates log data from across an organization's entire IT infrastructure—including servers, firewalls, network routers, identity systems, and endpoint devices—to detect security threats in real time and maintain compliance.

Core Components: ( SIM + SEM )

A SIEM combines two historically seperate capabilities

  • Security Information Management (SIM)
  • Security Event Management (SEM)

How a SIEM works

  1. Log Ingestion & Collection
  2. Parsing & Normalization
  3. Correlation & Analysis
  4. Alerting & Triage
  5. Storage & Compliance

Primary Capabilities & Features

  • Real-Time Dashboards
  • Correlation Rules
  • User & Entity Behaviour Analytics(UEBA)
  • Threat Intelligence Integration
  • Incident Investigation
