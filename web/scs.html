Source Code Scan

Source code scanning (commonly referred to as Static Application Security Testing, or SAST) is the automated analysis of an application’s source code, byte code, or binary code to detect vulnerabilities, security flaws, and compliance issues before software is compiled or deployed.

Types of Code Scanning:

  • SAST (Static Application Security Testing)
  • SCA (Software Composition Analysis)
  • Secret Scanning

Blackbox

In technology and cybersecurity, a black box refers to a system, device, or test where the internal workings, source code, or architecture are completely hidden or unknown to the observer. You can only interact with it by observing what inputs go in and what outputs come out.

Whitebox

White-box (also known as clear-box, glass-box, or open-box) refers to a testing, analysis, or design approach where the internal structure, source code, data paths, and implementation details of a system are fully visible and accessible to the examiner.
