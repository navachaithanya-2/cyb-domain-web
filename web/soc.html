Security Operations Center

A SOC (pronounced "sock"), or Security Operations Center, is a centralized team and facility within an organization responsible for monitoring, detecting, analyzing, and responding to cybersecurity incidents in real time.

While tools like SIEM aggregate the data, the SOC is the command center where security analysts actively use that data to defend the organization.

  1. Core Functions of a SOC

    • Monitoring & Detection
    • Alert Triage
    • Incident Response
    • Threat Intelligence & Threat Hunting
    • Root Cause Analysis & Post-Incident Review

  2. Traditional SOC Tiers and Roles

    1. Triage Analyst
    2. Incident Responder
    3. Threat Hunter/ Forensics
    4. SOC Lead / Manager

  3. Core SOC Technology Stack

    • SIEM (Security Information and Event Management)
    • EDR / XDR (Endpoint / Extended Detection and Response)
    • SOAR (Security Orchestration, Automation, and Response)
    • Threat Intelligence Platform (TIP)

  4. Key Performance Indicators(KPIs)

    • Mean Time to Detect(MTTD)
    • Mean Time to Acknowledge (MTTA)
    • Mean Time to Respond / Contain (MTTR)
    • False Positive Rate
