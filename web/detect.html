Detection

In cybersecurity, detection is the ability to discover, identify, and analyze unauthorized activity, malicious software, or policy violations within a network or computer system as quickly as possible.

Along with protection and response, it forms the core operational cycle of digital defense: while protection aims to keep threats out, detection acts as the alarm system when a threat manages to bypass those initial barriers.

  • Core Detection Methods

    • Signature-Based Detection
    • Anomaly-Based (Behavioral) Detection
    • Heuristic Analysis

  • Key Detction Tools

    • IDS (Intrusion Detection System)
    • EDR (Endpoint Detection & Response)
    • SIEM (Security Information & Event Management)
    • NDR (Network Detection & Response)

  • Key Metrics for Detection

    • Mean Time to Detect (MTTD)
    • Dwell Time
    • False Positive Rate
