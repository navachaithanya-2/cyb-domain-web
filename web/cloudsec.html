Cloud Security

Cloud Security encompasses the technologies, policies, controls, and services designed to protect cloud-based systems, data, and applications from cyber threats, unauthorized access, and vulnerabilities.

Unlike traditional on-premises security bounded by a physical perimeter, cloud security relies heavily on identity, logical isolation, and shared operational responsibilities.

  1. The Shared Responsibility Model

    • Infrastructure as a Service (IaaS)
    • Platform as a Service (PaaS)
    • Software as a Service (SaaS)

  2. Core Pillars of Cloud Defense

    • Identity & Access Management (IAM)
    • Cloud Posture & Configuration
    • Data Protection & Key Management
    • Network & Workload Protection

  3. Key Tooling Categories

    • CSPM (Cloud Security Posture Management)
    • CWPP (Cloud Workload Protection Platform)
    • CIEM (Cloud Infrastructure Entitlement Management)
    • CNAPP (Cloud-Native Application Protection Platform)

Federated Identity

Federated identity is an arrangement that allows a user to access multiple systems, applications, or websites across different organizations using a single set of login credentials.

Instead of creating and maintaining a separate username and password for every single service, trust is established between two main parties

Cloud Access Security Broker(CASB)

A Cloud Access Security Broker (CASB) is an on-premises or cloud-hosted software tool or service that sits between cloud service consumers (users, devices) and cloud service providers (SaaS, PaaS, IaaS apps). It acts as a gatekeeper, enforcing security, compliance, and governance policies across an organization's cloud usage.
