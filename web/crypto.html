Cryptography

Cryptography is the science and practice of securing communication and data so that only intended recipients can read and process it. It blends mathematics, computer science, and information theory to protect privacy and verify authenticity.

The three main types are:

  1. Symmetric Encryption

    • Uses a single shared key for both encryption and decryption. Very fast and efficient.
    • Common use cases are Hard drive encryption (AES-256), file storage, bulk data transfer.

  2. Asymmetric Encryption

    • Uses a key pair: a public key (anyone can see) to encrypt and a private key (kept secret) to decrypt.
    • Common use cases are Secure web browsing (HTTPS/TLS), digital signatures (RSA, ECC).

  3. Cryptographic Hash Functions

    • A one-way mathematical function converting data into a fixed-length string (digest). Cannot be reversed.
    • Common use cases are Password storage, tamper-detection, blockchain (SHA-256).
